# OSS First Research Skill (Codex & Agent)

## Overview
When asked to build or implement a new tool, service, or feature:
1. **DO NOT WRITE CODE IMMEDIATELY.**
2. Search GitHub / package registries for existing, actively maintained open-source projects or libraries that solve the problem.
3. Evaluate candidates based on:
   - Maintenance status (recent commits, active issues/PRs, stars)
   - Setup/deployment complexity (dependencies, licenses like MIT/Apache)
   - Reusable features vs missing requirements (fit-gap analysis)
4. Present the decision recommendation (1: Use as-is, 2: Fork/modify, 3: Build from scratch) and propose the minimal MVP plan.
5. Wait for explicit human confirmation before writing code.
