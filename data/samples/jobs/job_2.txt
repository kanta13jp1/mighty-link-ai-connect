【案件名】大手ECサイトフロントエンド全面リプレイスプロジェクト
【募集企業】大規模ECプラットフォーム運営会社 (コード品質・パフォーマンス重視)
【勤務地】週1日出社 (東京都渋谷区) / 残りリモート
【想定年収/月単価】70万円 〜 85万円 / 月

■ プロジェクト概要
月間数千万PVを誇る大規模ECサイトのフロントエンド環境（レガシーなjQuery構成）を、モダンなコンポーネント指向フレームワーク（Vue.js/Nuxt.js または React/Next.js）へ全面的にリプレイスするプロジェクトです。
UIのパフォーマンス最適化、表示速度（Core Web Vitals）の改善、および一貫したデザインシステムに基づくピクセルパーフェクトなマークアップを追求しています。

■ 業務内容
- レガシーフロントエンドから Vue.js (Nuxt.js) または React (Next.js) へのコンポーネント設計・コーディング
- TailwindCSS または Vanilla CSS/Sass を用いた、Figmaデザインに100%忠実なレスポンシブUIの実装
- 大規模トラフィックを考慮したフロントエンドパフォーマンスチューニング (SSR, 静的プレレンダリング)
- Figmaを基盤とした社内共通デザインシステムとの連携・UIライブラリ構築

■ 必須要件 (Mandatory)
- JavaScript (ES6+) および CSS (Sass/Sass-like, CSS Modules) の実務経験 3年以上
- Vue.js / Nuxt.js または React / Next.js を用いた商用SPAの開発実務経験 2年以上
- Figma から正確なマークアップを行う実装力（ピクセルパーフェクト）
- レスポンシブウェブデザインの深い理解

■ 歓迎要件 (Preferred)
- TypeScript を用いた型安全なフロントエンド開発経験
- Jest や Playwright 等を用いたUI自動テストの導入・運用実績
- Webpack/Vite などのフロントエンドビルドツールの最適化知識

■ 求める人物像・開発文化
- デザイナーやプロダクトオーナーと密に連携し、美しいUI/UXを追求できる方
- レガシーなコードを辛抱強く紐解き、モダナイズすることを楽しめる方
- コードレビューにおいて、お互いのコードの品質向上に前向きに取り組める方
