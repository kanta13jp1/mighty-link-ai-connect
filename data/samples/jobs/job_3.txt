【案件名】機械学習・ビッグデータ解析プラットフォーム開発・分析プロジェクト
【募集企業】大手ITシンクタンク (学術的アプローチ・高信頼性重視)
【勤務地】フルリモート可 (月2回オフィスミーティングあり)
【想定年収/月単価】90万円 〜 120万円 / 月

■ プロジェクト概要
大手顧客向けに蓄積された数十億件規模の購買・行動データを活用し、需要予測や推薦アルゴリズムを構築するビッグデータプラットフォームの設計開発プロジェクトです。
OpenAI や Gemini API 等の各種LLMモデルのAPI連携、LangChainによるRAG（検索拡張生成）の実ビジネス適用、およびVertex AI/BigQueryを用いたMLOps体制の強化を推進しています。

■ 業務内容
- Python を用いた機械学習予測モデル（推薦、自然言語処理、売上予測）の開発と評価
- Google Cloud (BigQuery, Vertex AI) を用いたデータ分析基盤の設計・運用
- 各種LLM API (OpenAI, Gemini Pro) と LangChain を用いた社内高度テキスト検索APIの構築
- 機械学習モデルのデプロイ・サービング用Web APIの構築およびMLOps自動化

■ 必須要件 (Mandatory)
- Python を用いたデータ解析、機械学習の実務経験 4年以上
- PyTorch, scikit-learn, pandas などの標準データ解析ライブラリの深い知識
- SQL を用いた大規模リレーショナルデータ（BigQuery 等）の集計・クエリ最適化経験
- 機械学習モデルの評価指標および検証ロジックを自立して設計できる力

■ 歓迎要件 (Preferred)
- 自然言語処理 (NLP) または大規模言語モデル (LLM) のチューニング/LangChain適用実績
- GCP (Google Cloud) を用いたコンテナ環境およびVertex AIのパイプライン構築経験
- データサイエンスまたは数理情報工学分野の修士以上の数理的知識

■ 求める人物像・開発文化
- データの裏にある実態を数理的・統計的に見極め、ビジネス価値へ昇華させられる方
- 論文や最新技術（LLM動向など）のキャッチアップが早く、実験からプロダクション適用まで自走できる方
- 確かなセキュリティ設計と監査ログを重視し、高信頼なシステム作りにコミットできる方
