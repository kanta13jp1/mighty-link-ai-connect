## 1. 概要と目的

本仕様書は、「MightyLink AI Connect」のサービス料金プラン体系、利用制限枠、従量課金ルール、メーター計測仕様、および事業・原価根拠を明確に規定するプロダクト正本ドキュメントです。

- **対象市場**: 中小SES企業、派遣・人材サービス事業者、エンジニア組織。
- **基本価格戦略**: スモールスタートしやすい月額1万円未満（Standard: 月額¥9,800）を主力プロダクトとし、利用規模に応じた段階的SaaS料金体系（Free / Standard / Pro / Enterprise）を採用。
- **実課金管理**: Stripe Billing Meters API および Stripe Customer Portal による完全自動化。

## 3. 課金メーター（Billing Meters）仕様

本サービスでは、AIリソースを消費する2大機能を課金対象メーターとして定義・計測します。

| メーター識別子 (`meter_event_name`) | 対象機能 | 単位 | 課金ルール |
| :--- | :--- | :--- | :--- |
| `analysis_run` | AI適性・状況診断実行 | 診断1回 | プラン内込み回数を超過した分に対し、月末に確定従量課金 |
| `sales_email_match_run` | 営業メールAIマッチング・抽出実行 | マッチング1回 | プラン内込み回数を超過した分に対し、月末に確定従量課金 |
| `admin_export_run` | 管理者データエクスポート | 実行1回 | **非課金**（Freeプランの回数制限チェックのみに使用） |

### 冪等性・個人情報保護ガイドライン
- メーターイベントの送信時には、Stripe要求に従い `idempotency_key`（UUIDv4）を付与し、重複カウントを防止します。
- メーターのイベントペイロードにはユーザーIDまたは組織IDの匿名ハッシュ値のみを含め、個人識別情報（氏名・メールアドレス・文章本文等）は一切含めません。

## 4. 契約・決済・請求条件

1. **決済手段**:
   - クレジットカード決済（Stripe Checkout / Customer Portal）。
   - Enterprise プランのみ銀行振込（請求書払い）に対応。
2. **課金サイクル**:
   - サブスクリプション申込日に初回課金が発生し、以降毎月（または毎年）の同日に自動更新。
3. **プラン変更・解約ルール**:
   - **アップグレード**: 即時反映。旧プランの未利用日数は日割り計算（プロレーション）され、差額を即時請求。
   - **ダウングレード・解約**: Stripe Customer Portal より即時手続き可能。次回更新日をもって適用され、有効期間満了まで利用可能（未利用期間の返金は原則行いません。詳細は [BILLING_AND_REFUND_POLICY.md](BILLING_AND_REFUND_POLICY.md) を参照）。
4. **消費税・インボイス制度対応**:
   - 日本国内の消費税率（10%）を適用。Stripe Tax により自動税率計算を実施。
   - 適格請求書発行事業者登録番号（T番号）は Stripe 発行の領収書・請求書に記載。

## 5. 原価構造・損益分岐・価格設定根拠

1. **インフラ・AI原価構造**:
   - 固定インフラ費: Firebase / Supabase サーバーレス構成により、ベース費用月額 ¥0（無料枠内運用可能）。
   - AI変動原価: 診断1回あたり Gemini 経由で約 0.2〜0.5 円程度。
2. **損益分岐点 (Break-Even Point)**:
   - 月間固定コスト（ドメイン・ツール利用料等含む）は約 ¥5,000〜¥10,000。
   - Standard プラン（月額 ¥9,800）を **1 契約**獲得することで単月黒字化が達成される極めてスリムな高粗利率構造（粗利益率 90% 以上）。
3. **価格妥当性**:
   - 競合する適性診断ツールや営業AI分析サービス（月額数万円〜数十万円）と比較して圧倒的なコストパフォーマンスを提供し、中小企業の導入ハードルを最小化。

### 5.1. Pro/Enterprise 差別化機能ロードマップ
- **外部適性診断ツール「ミキワメAI」第1弾連携PoC (最優先開発)**:
