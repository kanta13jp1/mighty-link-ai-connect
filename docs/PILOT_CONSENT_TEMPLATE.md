# Mighty Skill-Bridge：AIフィット診断パイロット参加同意書（テンプレート）

**文書番号**: MSB-COMP-2026-001  
**適用開始日**: 2026年6月3日  
**対象範囲**: 本プロトタイプパイロットプログラム（方向性A：AIフィット診断支援）参加の全社内従業員および候補者  
**管理区分**: 社内秘・要同意署名  

---

株式会社 Mighty-Link（以下「当社」という）が実施する「Mighty Skill-Bridge：AIフィット診断パイロットプログラム」（以下「本パイロット」という）への参加にあたり、参加者（以下「甲」という）は、当社（以下「乙」という）による個人情報の収集、処理、およびAIモデル（Google Gemini API 等）への流し込みにおける匿名化規則について、以下の条項に同意するものとします。

### 第1条（利用目的）
乙は、甲から提供された経歴書（レジュメ）、スキルセット、およびアンケートデータを、以下の目的の範囲内でのみ利用します。
1. AIを用いた職務適性・案件マッチング（方向性A）のアルゴリズム精度検証。
2. 従業員間のスキルギャップ可視化および社内育成ロードマップ自動生成機能の評価。
3. 本システムのユーザビリティ向上および機能改善。

### 第2条（収集する情報項目と厳格な匿名化措置）
乙は、個人情報保護法および乙のプライバシーポリシーに基づき、収集するデータに対して以下の通り厳格な匿名化・マスキング（個人識別符号の除去）措置を施した上でAIエンジンへ連携します。

1. **直接的な識別子の完全除去（マスキング）**：
   * 氏名、生年月日、住所、電話番号、メールアドレス、所属部署名、および特定の個人を容易に識別できる固有名詞はAIシステムに送信する前に完全に削除、またはダミーID（例：`Candidate-A01` 等）に置換します。
2. **経歴書情報の一般化**：
   * 過去の勤務先企業名、学校名、具体的なプロジェクト固有名称等は、一般的な業種・職種（例：「大手SIerでのJava開発」➡️「ITサービス企業でのオブジェクト指向言語開発」）に置換・丸め処理を行い、AIの文脈解析に必要なスキル情報のみを抽出します。

### 第3条（外部AI API（Google Gemini API 等）連携における安全管理措置）
1. 乙は、甲のデータをAI処理するにあたり、Google Cloud / Gemini API の「データ保護およびオプトアウト規約」を適用し、**送信されたデータが外部モデルの公開学習データとして二次利用・蓄積されないプライベート・APIエンドポイント**を使用します。
2. 乙は、外部APIとの通信経路をSSL/TLSにより暗号化し、データの漏洩・不正アクセスを防止します。

### 第4条（データの保存期間および消去）
1. 乙は、本パイロット評価期間（2026年6月3日〜2026年6月16日）が終了した後、または甲から削除依頼があった場合、収集した生データおよびAI生成結果を3営業日以内に物理的・論理的に復元不可能な方法で完全消去します。
2. システム監査用の判定ログ（JSONL）は、完全匿名化されたID情報のみを保持し、最大6ヶ月保管した後に自動消去されます。

### 第5条（同意の撤回）
甲は、本パイロットの実施期間中、いつでも乙に対して書面またはメールにて通知することにより、本同意を撤回し、参加を中止することができます。この場合、乙は速やかに甲のデータを破棄します。
