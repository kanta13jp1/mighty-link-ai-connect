/frontend-design

インストールしたfrontend-design Skillを使い、初版のAI Agent Learning Hubを改善してください。

変更すること:
- 情報の優先順位、タイポグラフィ、余白、配色を整え、研修で投影しても読みやすいデザインにする
- 「すべて／開発／ナレッジワーク／計画・自動化」の絞り込みを追加する
- 各製品に「比較に追加／追加済み」ボタンを追加し、最大2製品を選べるようにする
- 選択件数、製品名、向いている仕事を比較サマリーへaria-liveで表示する
- app.jsを追加し、aria-pressed、キーボード操作、上限2件の案内に対応する
- #00A5E3、#EF7E00、緑、白、濃い文字色を使い、単一色に偏らない業務向けデザインにする

維持すること:
- 5製品の名称と公式情報に基づく説明
- KiroのSteeringとPowersを、Kiro固有の正式機能として説明すること
- AntigravityへKiroの機能名を誤って付けないこと
- ローカル画像、外部依存なし、送信なし、永続保存なし、commitとpushなし

検証すること:
- 製品件数が5件、フィルター件数が5・4・1・5になること
- 2製品選択時に件数、名称、向いている仕事が表示されること
- 3製品目を選ぶと追加せず、上限2件の案内が表示されること
- 1440x900と390x844で横スクロール、文字切れ、重なりが0であること
