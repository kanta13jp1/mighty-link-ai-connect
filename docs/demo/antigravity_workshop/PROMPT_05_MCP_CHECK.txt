Prompt 5 / Canva MCPの接続と利用可能Toolを読み取り確認する

Antigravity 2.0のSettings > Customizations > Installed MCP Serversで、Canva remote MCPの接続状態を確認してください。

確認条件:
- この段階ではCanvaデザインを作成・編集・削除しない
- OAuth再認証を要求された場合は、その場で認証せず停止する
- APIキー、token、cookie、認証情報を表示しない

接続済みの場合は、読み取り専用Toolだけを使って次を確認してください。

1. 接続中のCanvaアカウント
2. design search / content readが利用可能か
3. presentation generationが利用可能か
4. design import / editingが利用可能か
5. PPTX export Toolの有無。なければCanva画面から手動Downloadとする

結果は次の5行だけで返してください。

MCP: CONNECTED または STOP
ACCOUNT: <emailまたは非機密のhandle>
READ / SEARCH: AVAILABLE または UNAVAILABLE
CREATE / EDIT: AVAILABLE または UNAVAILABLE
PPTX EXPORT: TOOL / MANUAL / UNAVAILABLE

STOPの場合は理由を1行だけ追加し、設定変更や認証を開始しないでください。
