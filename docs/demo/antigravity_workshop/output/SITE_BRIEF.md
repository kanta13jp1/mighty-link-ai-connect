# AI Agent Decision Guide Site Brief

SYNTHETIC_DATA_ONLY

## Purpose

Show that an AI agent can turn an explicit test specification into a polished, verifiable, publicly available product in a short live demo. The site itself helps a reader choose among five AI agents by the work to be done, not by a generic score.

## Audience

- Business and engineering leaders evaluating AI-agent adoption
- Developers comparing coding and specification-driven workflows
- Knowledge workers considering cross-tool delegation

## Product scope

1. Codex
2. Claude Code
3. Claude Cowork
4. Kiro
5. Antigravity

The site must not add adjacent products merely to make the catalog look larger. Depth, traceability, and a useful decision model are more important than product count.

## Required evidence

Each product profile must show:

- A locally served icon downloaded from an official product property
- The current public version and date, or an explicit statement that no product version is published
- The latest relevant official update with title, date, summary, and direct link
- The latest relevant official video and blog post with dates and direct links
- Official documentation, release history, and pricing links
- The date on which the sources were verified

## Decision model

The detailed comparison uses 13 practical dimensions:

1. Primary work
2. Interaction surface
3. Working method
4. Persistent instructions
5. Capability extensions
6. MCP and integrations
7. Browser capability
8. Parallel and background work
9. Automation and embedding
10. Evidence and review
11. Safety boundary
12. Pricing and usage limits
13. Adoption cautions

The UI lets the user filter by work scenario, search all profile text, and compare at most two products side by side.

## Accuracy rules

- Verified at: 2026-08-13 JST
- Use only first-party pages and first-party official video channels as evidence.
- Do not invent fixed daily or monthly request limits when the provider describes variable capacity.
- Do not present a model version as a product version.
- Claude Cowork is a SaaS product without a published semantic product version; say so directly.
- All external facts may change. Keep the verification date visible and link to the source beside the claim.
