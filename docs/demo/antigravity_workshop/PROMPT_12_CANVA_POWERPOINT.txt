接続済みのCanva remote MCPを使い、編集可能な16:9のCanva Presentationを新規作成してください。開始前にアカウントと利用可能Toolを読み取り確認してください。

安全境界:
- 現在ログイン中のデモ用Canvaアカウントを使う
- 既存デザインは編集・削除しない
- 新規Presentationは1件だけ作成する
- 認証、読取、生成、編集のいずれかを確認できなければSTOPする
- PPTX export Toolがなければ、書き出しはCanva画面で人が行う

ファイル名:
Antigravity 2.0 MCP Demo - AI Agent Web Delivery

目的:
AIエージェントがWeb制作を、期待結果、Tool実行、検証、公開まで進めることを3枚で説明する。

スライド構成:
1. 「AIエージェントはWeb制作をどこまで任せられるか」
   要件整理 → テスト仕様 → 実装 → Chrome検証 → 公開
2. 「テストを先に作ると、AIの作業を証拠で確認できる」
   TEST_SPEC → RED → 実装 → GREEN → 公開確認
3. 「Skill、MCP、人の責任を分ける」
   Skill=仕事の型、MCP=外部Toolとの接続、人=目的・権限・承認・停止条件

テンプレート:
Canva公式の「Clean and Professional Company Profile Presentation」を第一候補にし、利用できなければ同じ系統の白基調・clean・professionalな会社資料テンプレートを選ぶ。

デザイン要件:
- Canva Presentation、16:9、全3枚
- 白とチャコールを基調に、ティール、コーラル、ライムを役割別アクセントに使う
- 日本語本文24pt以上、タイトル40pt以上
- 1スライド1メッセージ。カードの羅列を避ける
- グラデーション、過度な角丸、紫主体を避ける
- 外部ロゴ、個人情報、APIキー、未確認の数値を入れない
- PPTX変換後も文字と単純図形を編集できる構造にする
- 候補が複数なら、投影時に最も読みやすい白基調案を選ぶ

完了条件:

- 3枚に文字切れ、重なり、キャンバス外要素がない
- 各スライドのタイトルと検査結果を返す
- Canva編集URLを返す
- PPTX書き出しはまだ実行しない
- 公開、共有範囲変更、既存デザインの編集・削除はしない
