# MightyLINK AI Workshop Demo Site Brief

SYNTHETIC_DATA_ONLY

このファイルの内容は研修用の合成データであり、実在する顧客、社員、申込情報を含まない。公開サイトでは「研修用サンプルサイト」と表示する。

## サイト目的

AI研修の参加者が、4つのサンプルセッションを短時間で比較し、興味のあるセッションを参加候補として選べるWebサイトを作る。

## /grill-meで確定する判断

- 読み手: Web開発未経験の社員
- 1画面の仕事: 4セッションを比較し、参加候補を2件まで選ぶ
- 必須: セッション名、カテゴリ、時間、概要、絞り込み、選択状態
- 今回やらない: 申込フォーム、ログイン、データ送信、永続保存、分析タグ
- 公開境界: このファイルとローカル画像に含まれる合成情報だけ
- 成功条件: 4カード、カテゴリ件数`4,1,1,1,1`、2件選択、2 viewport、公開HTTPS URL

## 表示内容

- サイト名: MightyLINK AI Workshop Demo
- 見出し: AIを、明日の仕事で試してみる。
- 説明: 4つのミニセッションから、業務で試したいテーマを選ぶための研修用サンプルサイト。
- 注記: 研修用サンプルサイト / 入力・選択内容は送信されません

## セッション

| セッション | カテゴリ | 時間 | 概要 |
| --- | --- | --- | --- |
| AIで仕事を整理する | 業務改善 | 20分 | 日々の業務を分解し、AIに任せる範囲と人が判断する範囲を整理する。 |
| 伝わる文章をレビューする | コミュニケーション | 25分 | 社内文書を題材に、目的と読み手に合わせた改善案を比較する。 |
| データを見える形にする | 分析 | 30分 | 合成データから傾向を読み取り、確認すべきポイントを可視化する。 |
| 安全なAI活用を設計する | ガバナンス | 20分 | 合成データ、権限、レビュー、公開前確認の基本ルールを学ぶ。 |
