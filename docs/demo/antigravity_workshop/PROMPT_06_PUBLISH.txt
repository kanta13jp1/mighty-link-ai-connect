python -m unittest discover -s tests -vを実行し、T01-T08が8件PASSすることを確認してください。FAIL、テストの削除・skip・弱体化があれば公開せず停止してください。

commit messageと公開URLを報告したら停止し、「公開してもよいですか？」と質問してください。私が正確に「公開して」と答えるまでgit add、commit、push、GitHub設定変更を行いません。
