Prompt 1 / /find-skillsで専門能力を探す

/find-skills

5製品を比較するAI Agent Learning Hubの、情報設計、Webデザイン、レスポンシブ品質、アクセシビリティを改善できるAgent Skillを探してください。

最初に利用可能なSkillカタログを確認し、必要ならSkills CLIで npx skills find "frontend design" を実行してください。候補は3件までに絞り、次を比較してください。
- Skill名と用途
- 公開元とGitHub stars
- ライセンス
- セキュリティ監査（SKILL.md、scripts、外部通信、実行コマンドの監査結果）
- project-localのインストール方法
- 公式またはrepository URL

インストール数や公開元とGitHub starsだけで安全性を判断しないでください。公開元、内容、権限、変更範囲を確認して推奨を1件選び、このデモで改善する点を2行で説明してください。

まだSkillのインストール、ファイル変更、外部サービスへの書き込みは行わないでください。
