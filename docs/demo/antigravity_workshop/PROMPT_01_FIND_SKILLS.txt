Prompt 1 / /find-skillsで専門能力を探す

/find-skills

5製品を比較するAI Agent Learning Hubの、情報設計、Webデザイン、レスポンシブ品質、アクセシビリティを改善できるAgent Skillを探してください。

最初にskills.shの上位候補を確認し、次にSkills CLIで`npx skills find "frontend design"`を実行してください。候補は3件までに絞り、次を表で比較してください。
- Skill名と用途
- インストール数
- 公開元とGitHub stars
- セキュリティ監査の結果
- インストールコマンド
- skills.shのURL

公開元の信頼性、利用実績、監査結果を確認して推奨を1件選び、このデモで何を改善させるかを2行で説明してください。まだSkillのインストール、ファイル変更、外部サービスへの書き込みは行わないでください。
