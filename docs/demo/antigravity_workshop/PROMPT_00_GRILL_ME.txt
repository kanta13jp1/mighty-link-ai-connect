Prompt 0 / /grill-meで実装前の判断を固める

/grill-me

30分のライブデモで「AI Agent Learning Hub」という1ページWebサイトを作ります。実装前に、矛盾や不足がないか厳しく確認してください。

確定済みの前提:
- 観客は非エンジニアと開発者の混在
- サイトはCodex、Claude Code、Claude Cowork、Kiro、Antigravityの5製品を短時間で比較できる研修用成果物
- ゴールは、観客がAIエージェントによる要件整理、制作、改善、検証、公開の流れを理解すること
- 5製品の公式機能を比較するが、ライブ操作はAntigravityだけを使う
- 公開可能な製品説明とローカル画像だけを使い、個人情報、顧客情報、認証情報は使わない
- ログイン、フォーム送信、外部API、分析タグ、永続保存は作らない
- 専用GitHub Pagesリポジトリだけへ公開する
- 30分以内にSkill導入、初版作成、改善、公開確認まで見せる

実装結果を大きく変える質問だけを最大2問、1問ずつ質問してください。各質問には推奨回答と、その理由を1行で添えて、私の回答を待ってください。私が「推奨案で進めてください」と答えた場合は、その推奨回答を採用してください。

回答後に「決定事項／見送ること／停止条件／成功条件」を4区分で要約してください。この段階ではファイル変更、コマンド実行、外部通信を行わないでください。
