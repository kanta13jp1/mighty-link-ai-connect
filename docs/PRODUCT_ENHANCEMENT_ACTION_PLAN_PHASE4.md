# 🚀 プロダクト強化 フェーズ4仕様書・設計書 (T972〜T975)

本ドキュメントは、第4期PdMレビューに基づき、世界トップティアSaaS（Salesforce Agentforce, Stripe Billing, Linear, Chrome Extensions等）水準へ到達するための4大進化アクション（T972〜T975）の技術仕様書です。

---

## 1. Action 13: 複数エンジニア・チーム一括アサインAI最適化 (T972)

### 1.1 背景と目的
大型受託開発や複数名体制の案件（例: PM1名＋テックリード1名＋メンバー2名）に対し、メンバー同士の技術スタック重複を排除し相乗効果を最大化する「チーム提案パック」をAIが一括組成する。

### 1.2 主な仕様
- **モジュール**: `src/team_pack_matcher.py`
- **機能**:
  - 役割別アサイン（`Project Manager`, `Tech Lead`, `Senior Member`, `Junior Support`）。
  - チーム総合適合スコアおよび合計月額単価・スキル網羅率の算出。
  - クライアント向け「チーム提案書」の自動ドラフト生成。

---

## 2. Action 14: 自然言語対話型案件・人材探索AIエージェント (T973)

### 2.1 背景と目的
フォーム検索やフィルター操作を行わず、「来月空くGoエンジニア向けリモート案件ある？」とチャットで話しかけるだけで、即座に最適な案件候補と提案理由・提案文を返す対話型AIインターフェースを提供する。

### 2.2 主な仕様
- **モジュール**: `src/conversational_agent_explorer.py`
- **機能**:
  - 自然言語クエリ（希望言語、単価、稼働時期、勤務地等）の意図抽出。
  - 実案件プールからの動的コンテキスト検索と回答生成。
  - 提案文ドラフトへのワンクリック接続。

---

## 3. Action 15: 案件成約速度・競合応募倍率AI予測 (T974)

### 3.1 背景と目的
過去のメール取り込みデータと市場トレンドから、「この案件は平均3日以内に枠が埋まる人気案件（想定倍率4.2倍）」などの成約速度・応募倍率をAIが予測し、営業の提案優先度を最適化する。

### 3.2 主な仕様
- **モジュール**: `src/placement_velocity_predictor.py`
- **機能**:
  - `placement_velocity_days`（想定枠充足日数: 即日〜7日）。
  - `estimated_competition_ratio`（想定応募倍率: 1.5倍〜8.0倍）。
  - `proposal_urgency`（提案緊急度: HIGH / MED / NORMAL）と推奨営業アクション提示。

---

## 4. Action 16: ブラウザ拡張連携＆成果報酬連動型Stripe請求 (T975)

### 4.1 背景と目的
GmailやWeb求人管理画面（Wantedly/Green等）を見ながら右サイドバーから1クリックで人材照合・提案文コピーができるブラウザ拡張連携APIを提供し、マッチング成約時の成果報酬（Success-Fee）をStripe Billing Metersで自動計量・請求する。

### 4.2 主な仕様
- **モジュール**: `src/browser_extension_bridge.py`
- **機能**:
  - ブラウザ拡張用REST API（選択テキストからの瞬時マッチング＆提案文生成）。
  - 成約成功イベント（Placement Success Event）のStripe Billing Meters計量連携。
  - ハイブリッド課金（SaaS月額 ＋ 成約成果報酬）の自動台帳記録。
