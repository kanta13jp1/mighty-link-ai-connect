## 1. 年次見直しスケジュール

| 月 | 作業内容 | 担当 |
| :--- | :--- | :--- |
| **毎年1月** | 法改正チェック・改定要否の判断 | Claude Code + 人間 |

## 2. 法改正チェックリスト（年次）

### 2.1 個人情報保護法（日本）

```
[ ] 個人情報保護委員会のガイドライン改正通知を確認
    https://www.ppc.go.jp/personalinfo/legal/
[ ] 「要配慮個人情報」定義の変更有無を確認
[ ] 第三者提供・共同利用ルールの変更有無を確認
[ ] 越境データ移転規制（GCP/Supabase 利用）への影響を確認
[ ] 漏洩報告義務（3,000件以上 or 要配慮情報）の変更有無を確認
```

### 2.2 GDPR（EU 一般データ保護規則）

```
[ ] EU Data Protection Board (EDPB) の新ガイドライン確認
    https://edpb.europa.eu/our-work-tools/general-guidance/guidelines-recommendations-best-practices_en
[ ] 標準契約条項（SCC）の改定確認（Supabase / Google との DPA）
[ ] Cookie 同意要件の変更確認
[ ] Article 17（消去の権利）運用への影響確認
```

### 2.3 電気通信事業法（日本）

```
[ ] 外部送信規律（第27条の12）の適用範囲変更確認
    ※ Firebase Analytics / Google Analytics 使用時に該当
[ ] プライバシーポリシーへの「外部送信情報」記載要否の再確認
```

### 2.4 サービス変更トリガーによる臨時見直し

以下の変更が発生した場合は、年次を待たず即時に見直しを実施する：

```
[ ] 新しい個人情報の収集開始（例: 生体情報・位置情報・決済情報）
[ ] 第三者提供先の追加（例: Stripe 決済連携 T776）
[ ] 利用目的の変更（例: AI診断から採用支援への拡張）
[ ] データ保管国・リージョンの変更
[ ] 子供（13歳未満）のユーザー対応追加
```

## 3. 改定手順

### Step 1: 改定案作成

```
1. 現行版を docs/TERMS_OF_SERVICE.md / docs/PRIVACY_POLICY.md から取得
2. 変更箇所を diff 形式で docs/TERMS_CHANGELOG.md に記録
3. 改定案を Git ブランチ（feature/terms-update-YYYY）で管理
```

### Step 2: レビュー

```
1. 開発担当が内容確認
2. 重要な変更（利用目的・第三者提供追加）は外部弁護士レビューを実施
3. レビュー完了後に main ブランチへマージ
```

### Step 3: ユーザー通知

改定内容の重要度に応じて通知方法を選択する：

| 改定の重要度 | 通知方法 | 事前告知期間 |
| :--- | :--- | :--- |
| 重要（利用目的・第三者提供変更） | アプリ内バナー + 登録メール一斉送信 | **30日前** |
| 軽微（誤字修正・文言明確化） | 改定履歴ページへの記載のみ | 当日 |

```python
# scripts/send_terms_update_notice.py
# 利用規約改定通知メールを全ユーザーに送信
#
# 処理:
# 1. Supabase profiles からアクティブユーザーのメール一覧取得
# 2. Gmail API / SendGrid 経由でメール送信
# 3. 送信結果を data/terms_notice_log.tsv に記録
```

### Step 4: 公開・施行

```
1. 改定版を本番フロントエンド（/terms / /privacy）に反映
2. 改定日・バージョンをページ上部に明示
3. 旧バージョンをアーカイブ（/terms/archive/YYYY）として保持
4. docs/TERMS_CHANGELOG.md に改定履歴を追記
```

## 5. プライバシーポリシー必須記載事項チェックリスト

個人情報保護法・GDPR への準拠確認として、以下が現行ポリシーに含まれていることを年次で確認する：

```
【個人情報保護法（日本）必須項目】
[ ] 収集する個人情報の項目
[ ] 利用目的
[ ] 第三者提供の有無と提供先
[ ] 共同利用する場合はその旨と共同利用者の範囲
[ ] 開示・訂正・削除・利用停止の請求方法
[ ] 個人情報取扱責任者の氏名・連絡先
[ ] 苦情申し出先（個人情報保護委員会）

【GDPR（EU）必須項目】
[ ] データコントローラーの連絡先
[ ] 処理の法的根拠（同意 / 契約 / 正当な利益）
[ ] 保持期間
[ ] データ主体の権利（アクセス・削除・ポータビリティ・異議申し立て）
[ ] 第三国移転の情報（Supabase EU サーバー利用の場合）
[ ] 自動意思決定・プロファイリングの有無（AI診断の説明）
[ ] DPO（データ保護責任者）の連絡先（義務に該当する場合）
```
