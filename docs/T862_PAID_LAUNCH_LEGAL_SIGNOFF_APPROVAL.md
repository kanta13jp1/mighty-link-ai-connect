## 2. 有償公開前必須4件（T798-17〜T798-20）の最終確定内容

1. **T798-17（重大障害時の返金・クレジット構成）**:
   - 当社の責に帰すべき重大な障害により SLA 目標を下回った場合、原則として次回更新時に適用可能なクレジット付与を第一選択とし、解約時や顧客の申し出に対して Stripe Refunds API 経由での現金返金を行う（[`docs/BILLING_AND_REFUND_POLICY.md`](BILLING_AND_REFUND_POLICY.md) 第5条第2項）。
2. **T798-18（例外返金時の Stripe 決済手数料控除）**:
   - 当社に過失のない例外的な返金処理において、返還されない Stripe 決済手数料相当額（約3.6%）を控除する（同 第5条第4項）。
3. **T798-19（返金請求期限 30日）**:
   - 返金請求は対象請求発生日から 30 日以内にサポート窓口へ申し出るものとする（同 第5条第5項）。
4. **T798-20（改正特商法・最終確認画面の自動更新表示）**:
   - 申込最終確認画面にて(1)数量・期間、(2)販売価格、(3)支払時期・方法、(4)引渡時期、(5)解約方法、(6)申込期間を明記する（[`docs/TOKUSHOHO_NOTATION.md`](TOKUSHOHO_NOTATION.md)）。
