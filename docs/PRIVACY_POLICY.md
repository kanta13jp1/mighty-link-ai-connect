## 3. 利用目的

1. AI を用いたエンジニアと案件の適合度診断（フィット分析・面談想定質問・育成ロードマップの生成）の提供
2. 職務適性・案件マッチングのアルゴリズム精度検証（パイロット期間）
3. スキルギャップ可視化・育成ロードマップ機能の評価・改善
4. システムのユーザビリティ向上・機能改善・不具合対応
5. 不正アクセスの検知・防止、セキュリティ監査
6. 利用状況の集計・分析（匿名化・統計化した情報による）
7. 利用者への重要なお知らせ・サポート対応
8. 法令に基づく対応

利用目的を変更する場合は、変更後の目的を本ポリシーの改定により公表します。

## 4. AI 処理・外部送信について

1. 本サービスは、診断処理のためアップロードデータのテキストを **Google Gemini API** に送信します。送信時は氏名等の直接識別子を除外・マスキングする運用とし（`docs/PILOT_CONSENT_TEMPLATE.md` のマスキング基準参照）、**学習データとして二次利用されないプライベート API エンドポイント**（データ保護・オプトアウト規約適用）を使用します。
2. 通信はすべて SSL/TLS で暗号化されます。
3. パイロット期間中のマスキング基準（氏名のダミー ID 化、生年月日の年代化、連絡先の完全削除、企業名の業種・規模への一般化等）は同意書テンプレートに定めるとおりです。
4. デモ動画生成に外部 API（BytePlus Seedance）を利用する場合がありますが、個人情報は送信しません。

## 7. 第三者提供

1. 当社は、次の場合を除き、本人の同意なく個人情報を第三者に提供しません。
   - 法令に基づく場合
   - 人の生命・身体・財産の保護に必要で本人同意の取得が困難な場合
   - その他個人情報保護法第27条第1項各号に該当する場合
2. 第三者提供を行った場合は、個人情報保護法第29条に基づき記録を作成し 3 年間保存します（`docs/PERSONAL_INFO_DISCLOSURE_PROCEDURES.md`）。現時点で第三者提供の実績はありません。

## 8. 安全管理措置

1. **アクセス制御**: Firebase ID トークンによる API 認証（第一層）と Supabase Row Level Security（第二層）の二重防御。本人以外はデータへアクセスできません。
2. **暗号化**: 通信の TLS 暗号化、監査ログの氏名マスキング・暗号化パイプライン（`docs/AUDIT_LOG_MASKING_AND_ENCRYPTION.md`）。
3. **クローズド運用**: パイロット期間中のアクセス範囲は社長・開発管理者等の限定メンバーのみ（`docs/PILOT_CLOSED_OPERATION_DESIGN.md`）。
4. **監査**: 日次ログ監査による PII リーク簡易スキャン、四半期セキュリティ監査（`docs/SECURITY_AUDIT_RUNBOOK.md`）。
5. **委託先監督**: DPA 締結済み事業者のみを利用し、定期的に認証状況を確認します。

## 10. Cookie・アクセス解析

本サービスは、セッション管理および利用状況の改善のために必要最小限の Cookie・ローカルストレージを使用します。WBS T800で導入した利用状況アナリティクスでは、ページ表示、主要セクション表示、ボタン・リンククリック、フォーム送信開始などのイベントを、匿名セッションIDを疑似ID化したうえで記録します。

アクセス解析では、氏名、メールアドレス、電話番号、フォーム本文、IPアドレス、生の User-Agent、URLクエリ文字列、APIキーやtoken等のsecretを保存しません。ブラウザ側の匿名セッションIDは `msb_usage_session_v1` としてローカルストレージに保存され、サーバー側では `usage-<digest>` 形式の疑似IDとして扱います。

アクセス解析を無効化したい場合は、ブラウザの開発者ツールで `localStorage.setItem("msb_analytics_opt_out", "1")` を実行するか、ブラウザのサイトデータを削除してください。本番公開前に一般利用者向けの同意UIを追加する場合は、本項と画面上の説明を再確認します。
