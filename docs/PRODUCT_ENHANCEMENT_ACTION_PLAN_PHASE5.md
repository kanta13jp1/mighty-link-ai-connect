# 🚀 プロダクト強化 フェーズ5仕様書・設計書 (T980〜T983)

本ドキュメントは、第5期PdMレビューに基づき、Harvey AI, Rippling, ServiceTitan, Stripe Connect等の業界トップクラスVertical SaaS水準へ到達するための4大進化アクション（T980〜T983）の技術仕様書です。

---

## 1. Action 17: SES個別契約書・発注書AI自動生成＆法定チェック (T980)

### 1.1 背景と目的
成約決定後の準委任契約・派遣契約における精算幅（例: 140h〜180h）、単価、支払いサイト、指揮命令権・偽装請負リスク条項をAIが自動チェックし、即時締結可能な個別契約書（Markdown/PDF）を生成する。

### 1.2 主な仕様
- **モジュール**: `src/ses_contract_generator.py`
- **機能**:
  - 準委任（善管注意義務・成果物責任なし）・派遣・請負の各類型に適合した条文自動生成。
  - 精算時間幅・過不足控除・支払いサイトの整合性検証。
  - 電子署名連携用メタデータ（CloudSign / freeeサイン互換）出力。

## 2. Action 18: リアルタイム需給連動・最大利益プライシングAI (T981)

### 2.1 背景と目的
案件の競合倍率・スキル希少性・クライアント予算上限から、成約確率80%以上を維持したまま最大利益を獲得できる提示単価（Yield Price）をAIが算出・提案する。

### 2.2 主な仕様
- **モジュール**: `src/yield_pricing_optimizer.py`
- **機能**:
  - 最適提示単価（Recommended Yield Rate: +5〜15万円/月）の算出。
  - 想定粗利額向上シミュレーション（Annual Profit Gain）。
  - クライアントへの値上げ打診根拠テキスト（Skill Premium Justification）生成。

---

## 3. Action 19: 稼働エンジニア離職・契約途中終了リスク早期検知 (T982)

### 3.1 背景と目的
稼働中エンジニアの月間残業時間推移、定例パルスサーベイの感情極性スコアから、退職・体調不良・現場不満による途中退場リスク（Churn Risk）を事前検知し、営業・フォロー担当へアラート通知する。

### 3.2 主な仕様
- **モジュール**: `src/talent_retention_predictor.py`
- **機能**:
  - 残業時間（45h超/過少稼働）およびパルススコア（1〜5点）によるリスク総合スコアリング。
  - アラートレベル（`GREEN_SAFE`, `YELLOW_WATCH`, `RED_CRITICAL_CHURN`）。
  - 営業向け即時予防アクションプラン（1on1ヒアリング、単価・環境交渉等）の自動提案。

---

## 4. Action 20: パートナー企業間クロスボーダー案件・人材シェアリング流通基盤 (T983)

### 4.1 背景と目的
自社単体ではアサインできない余剰人材や対応不能な空き案件を、認定済みパートナー企業ネットワーク内で相互流通させ、成約時の手数料分配（Take-rate）を自動計量・管理する。

### 4.2 主な仕様
- **モジュール**: `src/talent_exchange_network.py`
- **機能**:
  - 企業間プールへの匿名案件・人材の出品（Offer & Request）。
  - 企業間マッチング成立時の手数料（例: 月額成約額の5〜10%）自動計算。
  - Stripe Connect / Invoice 連携用流通台帳（GMV Ledger）の管理。
