# 🚀 プロダクト強化 フェーズ2仕様書・設計書 (T964〜T967)

本ドキュメントは、PdMレビュー（第2回）に基づき、世界的ヒットSaaS水準（Linear, Slack, Notion, Ramp等）へ到達するための4大進化アクション（T964〜T967）の技術仕様およびアーキテクチャ設計書です。

---

## 1. Action 5: 成約完結・提案文/打診文自動生成 (T964)

### 1.1 背景と目的
マッチングを発見した後の「案件元への提案メール作成」「エンジニアへの案件打診文作成」を自動化し、営業担当者がワンクリックで送信可能な完成原稿を取得できるようにする。

### 1.2 主な仕様
- **モジュール**: `src/proposal_generator.py`
- **生成モード**:
  1. **`client_proposal` (案件元向け提案文)**: 候補人材のスキル要約、合致理由、単価、稼働可能日、アピールポイントを含むプロフェッショナルな営業提案文。
  2. **`engineer_inquiry` (エンジニア向け打診文)**: 案件概要、必要スキル、やりがい・環境の魅力、想定単価、希望確認を含む親身な打診文。

## 2. Action 6: 瞬時オンボーディング・スキルシート一括AIパース (T965)

### 2.1 背景と目的
新規導入企業が手元にあるスキルシート（テキスト/PDF/Word/Markdown形式）をドラッグ＆ドロップするだけで、5秒で構造化データへ変換し即座にマッチング可能にする。

### 2.2 主な仕様
- **モジュール**: `src/skill_sheet_parser.py`
- **抽出項目**: 氏名/イニシャル、経験年数、主要スキル一覧（言語・フレームワーク・DB・クラウド）、希望単価、稼働開始可能日、自己PRサマリ。

---

## 3. Action 7: Slack/Teams 双方向インタラクティブアクション (T966)

### 3.1 背景と目的
通知カードから直接「提案する」「キープ」「見送り」ボタンを押すだけで、WebUIを開かずにフィードバックを即時登録できるようにする。

### 3.2 主な仕様
- **モジュール**: `src/interactive_webhook.py`
- **アクション処理**:
  - `action_type="propose"` -> 提案中ステータスへ更新＋提案ドラフト生成トリガー
  - `action_type="keep"` -> 保留リストへ追加
  - `action_type="reject"` -> 却下理由の記録（AIフライホイールへ自動環流）

---

## 4. Action 8: SES市場相場インテリジェンス分析 (T967)

### 4.1 背景と目的
取り込んだ月3万件規模の営業メール群から、スキル別平均単価、案件数トレンド、需要急増ポジションを自動集計し、Pro/Enterprise向けの高付加価値マーケットインサイトを提供する。

### 4.2 主な仕様
- **モジュール**: `src/market_intelligence.py`
- **提供指標**:
  - 主要スキル別平均単価（例: Go: 85万円, Python: 82万円, Java: 75万円）
  - 需要急増トレンド（前月比 +20%以上のキーワード）
  - リモート可否比率
