## 3. 外部弁護士への重点質問状 (全4領域)

### 領域①：AI生成物の免責・著作権帰属および賠償責任上限

- **Q1-1 (AI診断・マッチングの免責)**:
  - 利用規約第6条において、AIによる解析・マッチング結果について「正確性・適合性を保証せず、利用者の自己責任において利用する」旨を規定しています。この免責構成は消費者契約法第8条（事業者の損害賠償責任を全部免除する条項の無効）との関係で問題ありませんか？
  - **社内ドラフト案**: 故意または重過失がある場合を除き、免責される旨を但し書きとして明記。
- **Q1-2 (AI生成物の権利帰属)**:
  - 利用規約第10条において、利用者が入力したデータから生成された出力（マッチング結果、メール下書き等）の権利を利用者に帰属させ、当社はサービス提供に必要な範囲で無償利用許諾を受ける構成としています。著作権法上の観点から問題ありませんか？
- **Q1-3 (損害賠償額の上限)**:
  - 利用規約第14条において、当社の損害賠償責任の上限を「直近12か月間に利用者が当社に支払った対価の合計額」または「1万円」のいずれか高い額に制限しています。法人・個人双方を対象とするB2B/B2C混在サービスとして妥当でしょうか？

### 領域②：労働関連法令（職業安定法・労働安全衛生法等）との整合性

- **Q2-1 (職業安定法との関係)**:
  - 本サービスのマッチング機能は、スキル情報と求人案件情報の機械的照合・提示を行うものであり、求職・求人の申し込みの受託や個別の斡旋を行うものではありません。職業安定法第5条の5（求人情報の的確な表示等）および職業紹介事業の許認可規制に該当しない構成として妥当でしょうか？
- **Q2-2 (従業員適性・状態把握と労安衛法)**:
  - 社内向け適性・状態診断ツールにおいて、精神状態や健康状態に関するデータはDBへ永続保存せず、デモ画面上でのセッション限定表示としています。労安衛法第66条の10（ストレスチェック）等の規制対象外として整理可能でしょうか？
  - **社内ドラフト案**: 医療行為・心理診断ではなくセッション限りのセルフチェックとして位置づけ。

### 領域③：個人情報保護法対応（要配慮情報・第三者提供・外国移転）

- **Q3-1 (営業メールにおける第三者個人情報の取得)**:
  - 営業メール機能において、取引先担当者の氏名・メールアドレス等を個人データとして利用します。個人情報保護法第20条（適正な取得）・第21条（利用目的の通知・公表）の観点から、プライバシーポリシー§2/§3の公表記載で十分な取得根拠となりますか？
- **Q3-2 (外国にある第三者への提供とクラウドインフラ)**:
  - 当社は Supabase / OpenAI / Anthropic 等の外部クラウド・AI APIサービスを利用しています。法第28条（外国にある第三者への提供の制限）の観点から、プライバシーポリシー§5での「利用者の同意または同意と同等の保護措置」の記載内容で法的要件を満たしていますか？

### 領域④：消費者契約法・特定商取引法対応（解約・返金・自動更新）

- **Q4-1 (重大障害時の返金とクレジット付与の選択構成)**:
  - 課金規約第5条第2項において、当社の責に帰すべき重大障害時の補償として「次回更新時に利用できるクレジット付与」を第一選択とし、解約時または顧客希望時に「Stripe返金」を行う構成としています。消費者契約法および実務的観点から妥当でしょうか？
- **Q4-2 (例外返金時のStripe決済手数料控除)**:
  - 利用者都合による例外的な返金処理において、返金不可である Stripe 決済手数料（約3.6%）を返金額から控除する規定（課金規約第5条第4項）は法的効力を有しますか？
- **Q4-3 (改正特商法に基づく自動更新・最終確認画面)**:
  - 定期購入（サブスクリプション）の申込最終確認画面において、(1)数量・期間、(2)販売価格、(3)支払時期・方法、(4)引渡時期、(5)申し込みの撤回・解約に関する事項、(6)申込期間を明確に表示する設計（特商法表記ドキュメント）は、改正特商法ガイドラインの基準を満たしていますか？

## 4. 今後の弁護士レビュー実施手順とスケジュール

1. **弁護士選定・受任**: R36 担当外部弁護士（IT/個人情報/消費者法専門）への正式打診およびNDA締結
2. **レビュー実施**: 本パッケージ（`LEGAL_REVIEW_EXTERNAL_ATTORNEY_PACKAGE.md`）および各法定docsの提供
3. **回答・修正フィードバック受領**: 弁護士回答の受領および必要に応じた本文改訂
4. **T862決裁・有償化Go判定**: 弁護士確認の完了をもって、有償公開前必須4件のサインオフを完了し、T862有償公開を承認する。
