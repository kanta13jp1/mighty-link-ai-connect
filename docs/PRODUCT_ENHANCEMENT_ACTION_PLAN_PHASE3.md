# 🚀 プロダクト強化 フェーズ3仕様書・設計書 (T968〜T971)

本ドキュメントは、第3期PdMレビューに基づき、メガSaaS（Salesforce, Calendly, Ramp, Stripe等）水準へスケールするための4大進化アクション（T968〜T971）の技術仕様書です。

---

## 1. Action 9: AI面談日程自動調整＆Calendar連携 (T968)

### 1.1 背景と目的
提案承諾後のクライアント企業・エンジニア間の面談調整にかかる日程候補出し・連絡往復工数を自動化し、ワンクリックでGoogle/Outlook Calendar予定登録URLを発行する。

### 1.2 主な仕様
- **モジュール**: `src/interview_scheduler.py`
- **機能**:
  - 面談候補日時（平日3候補）の自動フォーマット生成。
  - Google Calendar `render` URL（日時・タイトル・場所・参加者プリセット）の生成。
  - Zoom / Google Meet オンライン面談用テキスト自動挿入。

## 2. Action 10: LP向け10秒インスタント・フリーマッチング体験 (T969)

### 2.1 背景と目的
未ログインの初回来訪者がLP上でスキルや希望条件を入力するだけで、匿名化された実案件プールから10秒で想定単価とマッチ案件3件を表示するバイラルPLGシミュレーターを提供する。

### 2.2 主な仕様
- **モジュール**: `src/instant_sandbox_matcher.py`
- **機能**:
  - スキル・希望単価に基づく高速インメモリマッチング。
  - 個人情報・顧客企業名を完全にマスキングした安心の匿名プレビュー。
  - 「無料アカウント作成で詳細と自動提案文を見る」CTA導線。

## 3. Action 11: 商流深さ・取引先信用度AIスコア (T970)

### 3.1 背景と目的
メール本文の文脈から多重下請け商流（エンド直 / 元請け / 2次請け以降）および支払いサイト（30日/60日等）をAI解析し、地雷案件を回避する業界特化の信用度スコアを提供する。

### 3.2 主な仕様
- **モジュール**: `src/client_credibility_scorer.py`
- **評価基準**:
  - `商流判定`: エンド直 (100点) / 元請・プライム (90点) / 2次請 (70点) / 多重下請 (40点)
  - `支払い条件`: 30日サイト (100点) / 45日サイト (85点) / 60日超 (50点)
  - `総合信用インデックス`: 0〜100点およびリスク警告タグ付与。

---

## 4. Action 12: Enterprise向け全操作監査ログ (T971)

### 4.1 背景と目的
大企業・上場SES企業のセキュリティ監査（SOC2 / ISO27001）に対応するため、全ユーザー・管理者の操作ログ（マッチング実行、エクスポート、個人情報閲覧）を改ざん防止ハッシュ付きでCSV/JSON出力する。

### 4.2 主な仕様
- **モジュール**: `src/enterprise_audit_trail.py`
- **機能**:
  - 操作ログレコード（日時、ユーザーID、操作種別、対象リソース、IPアドレス、SHA-256署名）。
  - 改ざん検証関数（Verify Chain Integrity）。
  - Enterprise専用監査レポート（JSON/CSV）出力。
