## 社長向け承認判断

**承認推奨。** 一度の生成結果を見せるだけでなく、追加指示でWebサイトが育ち、人が公開を承認し、実際のURLで成果を確認するところまでを一続きで示せる。公開先は専用GitHub Pagesリポジトリに分離され、本番`mightylink-app.com`へ影響しない。

承認後も次の条件を固定する。

1. 当日朝にH1-H10と回帰テストを再実行する。
2. 合成データと専用リポジトリ以外を使わない。
3. Prompt 3の`公開して`という人の承認を省略しない。
4. 90秒で進展がなければ完成版または読み取り専用予備へ切り替える。

この4条件を満たす限り、社長事前確認資料および社員研修の投影資料として使用できる。
