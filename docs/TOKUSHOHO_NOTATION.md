## 申込み最終確認画面の表示義務（2022 年改正特商法 / T791 実装要件）

通信販売の申込み（サブスクリプション申込を含む）の**最終確認画面**には、以下 6 項目を一括表示することが義務付けられている（特商法第12条の6）。Stripe Checkout / 申込 UI の実装（T791 / T745）では以下を満たすこと:

1. **分量**: プランの利用可能量（診断回数上限・ユーザー数等）
2. **販売価格・対価**: 税込価格。サブスクは更新ごとの金額、従量課金は単価と算定方法
3. **支払の時期・方法**: 初回課金日と更新課金日
4. **役務の提供時期**: 決済完了後直ちに利用可能である旨
5. **申込期間の定めがあるときはその旨**
6. **申込みの撤回・解除に関する事項**: 解約方法・返金ポリシーの要旨と詳細ページへのリンク

> [!WARNING]
> 定期購入（サブスクリプション）であることを最終確認画面で明示しない実装は特商法違反（誤認させる表示の禁止）となるため、Stripe Checkout の `custom_text` / 確認画面文言で「毎月自動更新される」旨を必ず表示する。【要法務確認】文言の最終確認。

- 公開ページは利用規約・プライバシーポリシーと同じ法定ページ群としてフッターから常時リンクする（T777）。
