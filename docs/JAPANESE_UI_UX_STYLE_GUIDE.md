# 🇯🇵 日本語 UI/UX スタイルガイド ＆ ドメイン正則用語集

本ドキュメントは、MightyLINK AI Connect における UI/UX 文言、エラーメッセージ、ヘルプテキスト、および操作案内の日本語表記に関する統一基準を定めるガイドラインです。

---

## 1. 基本方針（トーン＆マナー）

1. **ビジネス丁寧体（「です・ます」調）の統一**
   - 画面上のメッセージ、ダイアログ、ガイドテキストは「です・ます」調を基本とします。
   - 例: `保存しました` / `設定を更新してください` / `管理者認証が必要です`

2. **ボタン・タイトル等の体言止め活用**
   - ナビゲーションタブ、ボタン、見出し、箇条書きラベルは視認性と即時理解を考慮し、簡潔な体言止めまたは動作名を用います。
   - 例: `回答を送信` / `CSVダウンロード` / `質問を生成` / `管理者ダッシュボード`

3. **客観的サポート調（医療用語・処遇断定の排除）**
   - 「診断」「うつ」「精神障害」「適性不可」などの医療用語や人的処遇を断定する表現を厳格に排除します。
   - 代わりに「コンディション」「照合傾向」「面談での対話材料」などの客観的かつ安心感を与えるサポート表現を選択します。
   - 例: `精神状態判定` ❌ → `コンディション傾向` ⭕
   - 例: `不採用推奨` ❌ → `追加ヒアリング・面談での確認事項` ⭕

## 2. ドメイン正則用語集（Glossary）

UI全域における表記揺れを防止するため、主要機能・概念の正則名称を以下のように制定します。

| ドメイン領域 | 正則名称 | 許容する略称・文脈表現 | 非推奨・表記揺れNG例 |
|:---|:---|:---|:---|
| **営業メールAI** | **営業メールAIマッチング** | 営業メールマッチング, AIマッチング | 案件マッチ, メールAI, Sales Email Match |
| **適性・問診** | **社内適性・モチベーション診断** | 自己診断デモ, 適性診断 | 精神判定, メンタルチェック, 心理テスト |
| **勤怠・勤務表** | **勤務表・勤怠管理** | 勤怠打刻, 勤務表解析 | タイムカード, 出退勤アプリ, 作業報告 |
| **管理・運用** | **管理者統合ダッシュボード** | 管理者ダッシュボード, 管理画面 | Admin UI, 統合ボード, オペレーション画面 |

## 3. エラーメッセージ設計原則

ユーザーが操作に失敗した際、困惑させず次の正しい操作に誘導するための設計原則です。

1. **技術エラーコード・英語メッセージの非露出**
   - `400 Bad Request`, `401 Unauthorized`, `500 Internal Server Error`, `TypeError` などの生の英語やコードを直接見せず、自然な日本語文面で通知します。

2. **原因とアクション（解決策）の同時提示**
   - 単に「エラーが発生しました」と告げるのではなく、「何が原因で」「どうすれば解決するか」を明記します。
   - 良好な例: `フリー記述は10文字以上で入力してください。`
   - 良好な例: `管理者認証が必要です。正しいパスワードを入力してください。`
   - NG例: `Invalid payload detail`
   - NG例: `エラーコード 400`

3. **接続エラー時の親切なフォールバック**
   - 真のネットワーク切断やサーバー未到達時には、「サーバーに接続できませんでした。ネットワーク接続をご確認のうえ再試行してください。」と分かりやすく案内します。
