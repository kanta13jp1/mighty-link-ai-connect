# 課金規約・返金ポリシー（初版ドラフト）

> [!IMPORTANT]

## 第1条（適用範囲）

1. 本規約は、Mighty Skill-Bridge の有償プラン（サブスクリプションおよび従量課金）の課金・支払・解約・返金条件を定めます。
2. パイロット期間中の無償利用（利用規約第7条第1項）には本規約の課金条項は適用されません。

## 第2条（料金プランと課金方式）

1. 料金プラン・価格・無料枠・従量課金単価は、特定商取引法に基づく表記（`docs/TOKUSHOHO_NOTATION.md`）および申込画面に表示するとおりとします。【要確認】T804 で確定したプラン表をここに転記。
2. サブスクリプションは申込日に初回課金し、以後 1 か月ごと（年額プランは 1 年ごと）の更新日に自動課金されます。**プランは解約手続きをしない限り自動更新されます。**
3. 従量課金（診断回数等のメーター課金）は、当月利用分を翌月の請求日にまとめて課金します（Stripe Billing Meters / T791）。
4. 決済は Stripe を通じてクレジットカードで行います。当社はカード番号を保持しません。

## 第3条（プラン変更）

1. 上位プランへの変更（アップグレード）は即時適用し、差額は Stripe の比例配分（プロレーション）に従い精算します。
2. 下位プランへの変更（ダウングレード）は次回更新日から適用します。日割り返金は行いません。

## 第4条（解約）

1. 利用者は、アカウント設定画面（Stripe カスタマーポータル / T807）からいつでも解約できます。
2. 解約後も現課金期間の末日まで本サービスを利用でき、期間途中の解約による日割り返金は行いません。
3. 解約後のユーザーデータの取扱いは `docs/USER_DATA_DELETION_FLOW.md` に定めるとおりです（退会＝データ削除とは別手続）。

## 第5条（返金ポリシー）

1. 本サービスはデジタル役務であり、役務提供開始後の利用者都合による返金は原則として行いません。
2. 前項にかかわらず、以下の場合は当社の判断により全部または一部を返金（または次回請求への充当＝クレジット付与）します。
   - 当社の責に帰すべき重大な障害により、月間稼働率が SLA 目標（`docs/SLA_KPI_DEFINITION_AND_MEASUREMENT.md`）を著しく下回った場合【要法務確認】返金とクレジット付与の選択構成・算定基準
   - 二重課金・誤課金が確認された場合（全額返金）
   - 法令により返金が義務付けられる場合
3. 返金は Stripe Refunds API を通じて**元の支払方法に対してのみ**行います。返金の着金には通常 5〜10 営業日を要します。
4. 部分返金を行う場合があります。なお、返金時に当社が Stripe へ支払った決済手数料は Stripe から返還されないため、利用者都合の例外返金では決済手数料相当額を控除することがあります。【要法務確認】手数料控除の可否と表示方法。
5. 返金請求はサポート窓口（T790、`docs/USER_GUIDE_AND_FAQ.md`）へ、対象請求の発生日から 30 日以内に申し出るものとします。【要法務確認】請求期限の妥当性。

## 第6条（支払遅延・課金失敗）

1. クレジットカード決済が失敗した場合、Stripe のリトライ（Smart Retries）により再決済を試みます。
2. 再決済が一定期間（【要確認】Stripe ダッシュボードの dunning 設定: 7〜14 日を想定）成功しない場合、有償プランの提供を停止し、無償プラン相当へ降格または利用停止とします。
3. 支払遅延により当社に損害が生じた場合、当社は利用者へその賠償を請求できます。

## 第7条（価格改定）

1. 当社は、価格を改定する場合、適用開始日の 30 日前までに本サービス上の通知およびメールで告知します。
2. 改定後の価格は、サブスクリプションについては告知後最初に到来する更新日から適用します。利用者は更新日前に解約することで改定価格の適用を回避できます。

## 第8条（本規約の変更）

本規約の変更は、利用規約第14条【要確認】（規約変更条項）の手続に従います。重要な変更は 30 日前までに告知します。
