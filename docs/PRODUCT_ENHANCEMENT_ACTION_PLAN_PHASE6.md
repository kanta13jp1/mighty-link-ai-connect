# 🚀 プロダクト強化 フェーズ6仕様書・設計書 (T984〜T987)

本ドキュメントは、第6期PdMレビューに基づき、Palantir AIP, ServiceNow AI, OpenAI Enterprise等のウルトラメガAIプロダクト水準へ到達するための4大進化アクション（T984〜T987）の技術仕様書です。

---

## 1. Action 21: 面談対策・模擬面談AIコーチング (T984)

### 1.1 背景と目的
書類選考通過後の成約決定率を高めるため、案件票の技術要件（例: FastAPI / AWS / マイクロサービス）と候補エンジニアの経歴から予想される面談質問と模範回答・NG回答例をAI生成し、模擬面談ロープレを支援する。

### 1.2 主な仕様
- **モジュール**: `src/interview_roleplay_coach.py`
- **機能**:
  - 技術深掘り質問、チーム協調性質問、トラブル対応質問の自動出題。
  - エンジニア回答に対する評価・改善アドバイス（Score 1-100）。
  - クライアント企業面談官への逆質問（キラー質問3選）の生成。

---

## 2. Action 22: 自律型AIマッチング・オートパイロット提案 (T985)

### 2.1 背景と目的
朝の営業開始時に、夜間に受信した数百通の案件メールから最高適合ペア（適合スコア85%以上）をAIが自動選定し、ワンクリックで送信可能な提案ドラフト一覧を全自動生成する。

### 2.2 主な仕様
- **モジュール**: `src/sales_autopilot_engine.py`
- **機能**:
  - 夜間受信メールのバックグラウンド自動マッチング。
  - 重複案件排除・自社エンジニア稼働可能時期との自動突合。
  - 朝9時「即送信待ちキュー（Ready-to-Send Queue）」の生成。

---

## 3. Action 23: スキルシート魅力度向上リライト＆スキルアップAI (T986)

### 3.1 背景と目的
エンジニアの職歴書・自己PRを「採用企業に刺さる高付加価値な表現」へAIが自動リライトし、単価アップのための次期推奨スキル（Upskilling Roadmap）を提示する。

### 3.2 主な仕様
- **モジュール**: `src/skill_sheet_enhancer.py`
- **機能**:
  - 職歴・実績の定量的表現（例: 「API開発」→「月間1,000万req処理のFastAPI基盤設計・応答速度40%改善」）への自動推敲。
  - 単価+10万円アップのための習得推奨スキル3選のレコメンド。

---

## 4. Action 24: オンライン面談テキスト・合意条件自動抽出 (T987)

### 4.1 背景と目的
Zoom / Google Meet / Teams 面談の文字起こしテキストから、合意された「稼働開始日・単価・精算幅・残業見込み・担当領域」をAIが自動抽出し、契約書（T980）へ即時反映する。

### 4.2 主な仕様
- **モジュール**: `src/meeting_fact_extractor.py`
- **機能**:
  - 面談テキストからの重要ファクト（単価、時期、条件）自動抽出。
  - 契約書生成モジュール（`SESContractGenerator`）との直接連携。
  - 合意事項サマリ（Meeting Minutes Fact Sheet）の出力。
