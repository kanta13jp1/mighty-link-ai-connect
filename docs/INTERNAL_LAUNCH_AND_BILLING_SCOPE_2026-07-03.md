## 決定内容

2026-07-03、プロジェクトオーナー（梅澤寛太）が次を決定した。

1. **料金プラン仮決定の承認**: [PRICING_PLAN_PROVISIONAL_2026-07-03.md](PRICING_PLAN_PROVISIONAL_2026-07-03.md) の内容を当面の正とする（T804 完了）。
2. **当面は社内ユーザーのみが使用する**: 2026-07-08 の本番リリースは**社内向けGA（internal launch）**とする。
3. **課金機能は「仕組み」のみ実装する**: Stripe 課金は test mode での実装・検証（T791）までを完了条件とし、**live 課金は有効化しない**。実際の課金は発生しない。
4. **有償公開・live課金の時期は未定**: 一般公開・有償化の実施判断は新設の **T862** で行う（初回レビュー 2026-07-31、以後月次で再確認）。

## public_paid_launch ゲートへの影響（R112）

`data/release_go_no_go_criteria.tsv` の PUBLIC-xx ゲートは「一般公開・有償ローンチ」を前提に定義されている。今回の決定で 2026-07-08 のリリースが社内向けGAとなったため、有償化にのみ関係するゲート（Stripe live 検証等）の扱いを再定義する必要がある。これは R112 として起票し、2026-07-07 の T833 で関係者が確定する。

## 社内利用フェーズの運用原則

- Stripe は test mode のみ。live mode の API key・Webhook endpoint は設定しない。
- 課金 UI（/billing 導線）は動作確認のため残すが、実決済は発生させない。
- 特商法表記・課金規約の【要確認】箇所は有償公開まで確定させない（[TOKUSHOHO_NOTATION.md](TOKUSHOHO_NOTATION.md) の前提どおり）。
- 有償公開の判断材料（社内利用実績・コスト・SLA 実測）は T862 レビューへ月次で引き継ぐ。

## T862（有償公開・課金live有効化の実施判断）の完了条件

1. 経営判断として有償公開の実施可否・時期を決定する。
2. 実施する場合: CEO の最終価格確認（T804 の仮決定表の再承認または修正）、T807/T813/T793 の日程再設定、public_paid_launch ゲートの再有効化（R112 の再定義結果に従う）を行う。
3. 実施しない場合: 次回レビュー日を設定し、判断材料を更新して継続する。
