## 1. エグゼクティブサマリー

**「毎日届く大量の営業メール処理に追われ、本来の商談・マッチング提案に時間が割けない」** というIT人材・SES業界の課題に対し、**Mighty Link AI Connect** はメール取り込み、要件抽出、案件・人材候補の提示、人間レビューを一つの流れにまとめます。

2026-08-19時点で確認できる最新成果物は、702通の取込結果から案件378件、人材297件、スキルタグ531件を構造化したものです。ただし、この成果物は `deterministic-sales-email-extractor-v1` のfallback結果であり、ラベル付き正解データによる精度評価や1日1,000件の継続スループット試験ではありません。

```
【確認済みの処理フロー】
メール取込 ➔ deterministic抽出またはAI抽出 ➔ DB化 ➔ 候補提示 ➔ 人間レビュー

【今後測定する効果】
処理時間、提案までの時間、precision/recall、誤判定率、営業担当者の実作業時間
```

## 2. 現在の証拠とKPI測定計画

数値は「確認済み実績」「目標」「未計測」を分けて扱います。

| 評価項目 | 現在の証拠 | 判定 | 次の測定 |
| --- | --- | --- | --- |
| **取込・構造化件数** | 702通、案件378件、人材297件、タグ531件 | 確認済み | 日次流量と処理失敗率を継続記録 |
| **抽出方式** | deterministic fallback (`fallback_used=true`) | 確認済み | Gemini live時とfallback時を分離集計 |
| **スキル抽出・適合精度** | ラベル付き正解データなし | 未計測 | 100件以上を二者レビューしprecision/recallを算出 |
| **処理時間・営業工数削減** | before/afterの作業時間ログなし | 未計測 | 2週間の同一業務で中央値とP95を比較 |
| **1日1,000件処理** | 702通の単一成果物は存在 | 未検証 | 1,000件/日の連続負荷・再実行・重複排除を試験 |
| **セキュリティ・個人情報** | ハッシュ化、redaction、RLS、認証ガードを実装 | 技術統制あり | 法務未確定31件を解消し、人間サインオフを取得 |

## 3. 主な機能と営業活用シナリオ

### ① 営業メール自動解析・DB化
- **自動連携**: 共有営業アドレス（POP3/Graph API/Webhook等）宛の案件・人材メールをリアルタイム全件取り込み。
- **AI構造化抽出**: 必須スキル、尚可スキル、単価、勤務地、リモート可否、稼働時期、商流を自動抽出。

### ② 要員 × 案件のAI双方向マッチング候補
- **即時スコアリング**: 案件要件と求職者・パートナー要員の条件から候補スコアを算出。精度は人間レビュー結果で別途評価します。
- **適合根拠の可視化**: 単なるスコアだけでなく、「適合理由・非適合理由」をテキストで明示し、営業判断をサポート。

### ③ 統合ダッシュボード（管理者・営業向け共通画面）
- **一元管理**: 適性診断、勤怠管理、営業メールマッチング結果をセキュリティ保護されたWeb画面（Basic認証/ユーザー認証）でひと目で確認可能。
- **人間の最終チェック（Human-in-the-Loop）**: AIの提案を人間が1クリックでレビュー・承認して提案へ移行。
