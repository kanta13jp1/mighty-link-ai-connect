## 0. 前提（要配慮個人情報の取扱い）

適性・状態把握ツールが扱う心理・健康系データは、個人情報保護法上の **要配慮個人情報** に該当し得ます。法令に基づく場合等を除き、取得には **あらかじめ本人同意** が必要です（個人情報保護委員会ガイドライン）。したがって本ツールの導入では次を前提とします。

- 生回答・健康情報はベンダー側サービス内に閉じ、MightyLink / Supabase へは **集計・参照情報のみ** を保存する（データ最小化）。Supabase は SOC 2 Type 2 準拠で、健康データを扱う場合は HIPAA アドオンの要否も含めて別途評価する。
- 利用目的を **限定** し、本人同意・本人開示・利用停止の導線を確保する。
- 採用・評価への利用時は、属性差別・不利益取扱いを避ける設計とし、**自動判断ではなく人間レビュー** に使う。
- ストレスチェックを扱う場合、労働安全衛生法の実施者・プライバシー保護・不利益取扱い防止・面接指導・集団分析の流れを外さない（50人未満事業場も 2028-04-01 から義務化）。

## 1.1 T839 ベンダー評価結論および運用決定方針

PdM (小林 雅水) および法務・技術チームによる調査・確認に基づき、以下の運用方針を確定します。

1. **基本アーキテクチャ方針**:
   - MightyLink AI Connect 本体は、従業員の心理・健康データの生値（要配慮個人情報）を保存せず、**「評価メタデータ Hub」** として振る舞う。
   - 自社DB（Supabase）には「本人同意有無・受検完了日・非識別化集計カテゴリ」のみを記録し、生の診断スコアや自由記述テキストは連携・保存しない。
2. **ショートリスト3社の比較採点結論および第1弾優先ターゲット**:
   - **ミキワメAI (49点 / 第1弾優先PoC対象)**: エンジニアの採用・配属・適性判定と営業メールAIマッチング（スキル×適性）との連動効果が最も高く、第1弾の優先連携ターゲットとして決定。
   - **ラフールサーベイ (49点)**: ストレスチェック制度（労安衛法）適合度および組織健康経営の強固な基盤。
   - **HRBrain (48点)**: 人事評価・既存人事システムとのCSVデータ一元管理に長ける。
3. **DPA / 法務確認結論**:
   - 3社ともに SOC 2 / ISO 27001 等のセキュリティ認証を取得済みであり、インシデント通知SLA（72時間以内）およびデータ削除SLA（解約/退職後14日以内）を網羅。
   - 導入時のデータ連携は安全な CSV 手動エクスポート/インポートから開始し、生データ非保持の原則を厳格に維持する。

## 2. DPA / セキュリティ確認チェックリスト（条項レベル）

法務レビュー（T798 / R36）へそのまま渡せるよう、DPA（データ処理契約）の必須条項を確認する。各行はベンダー回答（有/無/条件）と根拠資料（DPA該当条・付属書）を記入する。

| # | 条項 | 確認内容 | ベンダー回答 | 根拠 |
| --- | --- | --- | --- | --- |
| 1 | 処理の範囲・目的 | 委託する個人データの種類・処理目的・期間が特定されているか | ☐ | |
| 2 | 再委託（サブプロセッサ） | サブプロセッサの一覧開示・事前承認・変更通知の仕組みがあるか | ☐ | |
| 3 | 国外移転 | データの保管・処理の所在国、越境移転の法的根拠（十分性/SCC等）が明示されるか | ☐ | |
| 4 | 安全管理措置 | 暗号化（保存時/通信時）、アクセス制御、認証、SOC 2 / ISO 27001 等の第三者認証 | ☐ | |
| 5 | インシデント通知 | 漏えい等発生時の**通知期限**（例: 認知後72時間以内）と連絡経路 | ☐ | |
| 6 | 削除SLA・削除証跡 | 契約終了/退職/同意撤回/PoC終了時の削除期限と、削除完了の**証跡**発行 | ☐ | |
| 7 | データ返還 | 契約終了時のデータ**返還**方式（形式・期限）と、返還後の消去 | ☐ | |
| 8 | 監査権 | 委託元の監査権・監査報告（SOC 2レポート等）の提供 | ☐ | |
| 9 | 本人の権利対応 | 開示・訂正・利用停止・データポータビリティへの対応と協力義務 | ☐ | |
| 10 | 秘密保持（NDA） | 秘密保持の範囲・存続期間・目的外利用禁止 | ☐ | |

## 4. 受領後の進め方

1. 各ベンダーの回答を §1 マトリクス・§2 チェックリストへ転記（生データはリポジトリに保存しない）。
2. §2 の DPA 条項確認結果を **T798 / R36 の外部法務レビュー** へ渡す。
3. 加重合計の最高点を第一候補とし、[EMPLOYEE_ASSESSMENT_SHORTLIST_POC_PLAN.md](EMPLOYEE_ASSESSMENT_SHORTLIST_POC_PLAN.md) の PoC 計画へ接続する。
4. 決定・課題は WBS（T839）・課題管理表へ反映する。
